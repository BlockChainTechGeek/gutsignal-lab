# Data

The intended dataset is **Bowel sounds** by Robert Nowak, published on Kaggle
under CC BY-NC 4.0 and associated with:

Ficek J, Radzikowski K, Nowak JK, Yoshie O, Walkowiak J, Nowak R. *Analysis of
Gastrointestinal Acoustic Activity Using Deep Neural Networks.* Sensors.
2021;21(22):7602. https://doi.org/10.3390/s21227602

Raw data is intentionally excluded from version control. The project must cite
the original dataset and remain non-commercial unless separate permission is
obtained.
